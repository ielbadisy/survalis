# Tune Penalized Cox Proportional Hazards Model via Cross-Validation

Performs hyperparameter tuning for penalized Cox models (glmnet) over a
grid of `alpha` values using cross-validation on one or more metrics.
Optionally refits the best model on the full dataset.

## Usage

``` r
tune_glmnet(
  formula,
  data,
  times,
  param_grid = list(alpha = seq(0, 1, by = 0.25)),
  metrics = c("cindex", "ibs"),
  folds = 5,
  seed = 123,
  ncores = 1,
  refit_best = FALSE,
  ...
)
```

## Arguments

- formula:

  A survival formula of the form `Surv(time, status) ~ predictors`.

- data:

  A `data.frame` containing all variables referenced in `formula`.

- times:

  Numeric vector of time points at which to evaluate performance.

- param_grid:

  A `data.frame` or list specifying candidate `alpha` values. Typically
  created with [`expand.grid`](https://rdrr.io/r/base/expand.grid.html).

- metrics:

  Character vector of performance metrics to compute. The first entry is
  used as the primary selection metric.

- folds:

  Integer; number of cross-validation folds. Default is `5`.

- seed:

  Integer random seed for reproducibility. Default is `123`.

- ncores:

  Integer number of CPU cores passed to
  [`cv_survlearner`](https://elbadisyimad.com/survalis/reference/cv_survlearner.md)
  for fold evaluation (default `1`).

- refit_best:

  Logical; if `TRUE`, fits the best configuration on the full dataset
  and returns the fitted model. If `FALSE` (default), returns a results
  table.

- ...:

  Additional arguments passed to
  [`fit_glmnet`](https://elbadisyimad.com/survalis/reference/fit_glmnet.md).

## Value

If `refit_best = FALSE`, returns a `data.frame` (class `"tuned_surv"`)
with hyperparameters and metric values for each grid combination, sorted
by the primary metric. If `refit_best = TRUE`, returns a fitted
`"mlsurv_model"` from
[`fit_glmnet`](https://elbadisyimad.com/survalis/reference/fit_glmnet.md).

## See also

[`fit_glmnet`](https://elbadisyimad.com/survalis/reference/fit_glmnet.md),
[`predict_glmnet`](https://elbadisyimad.com/survalis/reference/predict_glmnet.md)
